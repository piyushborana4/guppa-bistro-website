# 🍽️ Guppa Bistro — Premium Restaurant Website

A modern, interactive and animation-rich website designed for **Guppa Bistro**, a neighbourhood bistro in **Bandra West, Mumbai**.

The website combines **Mumbai's food culture with a modern editorial design**, creating an immersive digital experience focused on food, atmosphere and restaurant discovery.

> **Come hungry. Stay for the vibe.**

## 🎯 Design Concept

The website is inspired by the character of **Bandra and Mumbai's neighbourhood food culture**.

The visual direction combines:

* Mumbai street-food culture
* Café aesthetics
* Contemporary editorial design
* Parsi & Goan-inspired food influences
* Warm photography
* Hand-drawn details
* Modern motion design

The goal was to avoid the typical restaurant-template look and instead create a **distinct digital identity for the restaurant**.

## 📱 Responsive Breakpoints

The website is designed for:

* Desktop — 1440px+
* Laptop — 1200px
* Tablet — 768px
* Mobile — 480px
* Small Mobile — 375px

The mobile experience is intentionally designed rather than simply scaling down the desktop version.

---

## ⚡ Performance

The website uses performance-conscious animation techniques:

* Lazy-loaded images
* CSS transforms
* GPU-friendly animations
* Intersection Observer
* GSAP ScrollTrigger
* Optimized transitions
* Reduced-motion support

Large continuous JavaScript animations are avoided wherever possible.
